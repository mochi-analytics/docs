# Self-Hosting Mochi

Mochi runs as one app container plus Postgres (accounts/config) and ClickHouse
(events). A small VPS (2 GB RAM) handles it comfortably; ClickHouse idles around
0.5–1 GB.

## Docker Compose (recommended)

<Steps>

### Clone and start

```sh
git clone https://github.com/mochi-analytics/mochi
cd mochi
POSTGRES_PASSWORD=$(openssl rand -hex 16) \
CLICKHOUSE_PASSWORD=$(openssl rand -hex 16) \
docker compose -f docker/docker-compose.yml up -d
```

The compose file uses the published GHCR image tagged `latest`
(`ghcr.io/mochi-analytics/mochi`). The databases keep their data in named
volumes.

### Persist the passwords

Save the two generated passwords, for example in a `.env` file next to the
compose file:

```env filename=".env"
POSTGRES_PASSWORD=...
CLICKHOUSE_PASSWORD=...
```

### Create the admin account

Open `http://your-host:3000`. The first visit walks you through creating the
admin account.

<Callout type="warning">
  Put a TLS-terminating reverse proxy (Caddy, nginx, Traefik) in front for
  production.
</Callout>

</Steps>

Three background jobs are on by default in the compose file: migrations run at
startup (`MIGRATE_ON_START=1`), a daily job enforces each bot's retention
setting (`RETENTION_CLEANUP=1`), and a sweep evaluates [alert rules](/alerts)
every minute (`ALERTS=1`). Set any of them to `0` to manage that yourself.

## Environment variables

| Variable | Purpose |
|---|---|
| `DATABASE_URL` | Postgres connection string |
| `CLICKHOUSE_URL` / `CLICKHOUSE_USER` / `CLICKHOUSE_PASSWORD` / `CLICKHOUSE_DB` | ClickHouse connection |
| `MIGRATE_ON_START` | `1` = apply migrations at boot |
| `RETENTION_CLEANUP` | `1` = daily retention cleanup |
| `ALERTS` | `1` = evaluate alert rules and weekly digests every minute |

<Callout type="info">
  Running several Mochi containers against one database? Set `ALERTS=1` on
  exactly one of them. The sweep takes no cross-instance lock, so every instance
  that has it enabled will evaluate — and post — the same alerts.
</Callout>

## Upgrading

```sh
docker compose -f docker/docker-compose.yml pull
docker compose -f docker/docker-compose.yml up -d
```

Migrations apply automatically on boot.

## Developing Mochi

Requirements: Node 20+, pnpm, Docker.

```sh
pnpm install
pnpm db:up
pnpm --filter @mochi/web db:migrate
pnpm --filter @mochi/web ch:migrate
pnpm dev
```

Optional demo data:

```sh
pnpm --filter @mochi/web seed
```
